## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineOasis.git`
2. `cd OutlineOasis`
3. Install in editable mode: `pip install -e .`

## Configuration

OutlineOasis is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
